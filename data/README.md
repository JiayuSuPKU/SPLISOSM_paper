# Directory of datasets used in the SPLISOSM Paper

## Data folder structure
This folder contains the raw and processed spatial transcriptomics (ST) data used in this study and is organized as follows:
```
data/
├── README.md
├── gbm_ont_nc_23
├── gbm_visium_cell_24
├── human_dlpfc
├── simulation_data
├── sit_nar_23
├── slideseqv2_mouse_hippo
├── visium_mouse_cbs
```

All data files can be downloaded from [10.5281/zenodo.15556390 (DOI)](https://zenodo.org/records/15556390).

## Simulation data
The `simulation_data` folder contains the synthetic datasets used in this study, generated by [this script](https://github.com/JiayuSuPKU/SPLISOSM_paper/blob/main/scripts/benchmark/batch_simulation_full.py). Benchmark scripts for spatial variability and differential usage tests can be found [here (batch run)](https://github.com/JiayuSuPKU/SPLISOSM_paper/tree/main/scripts/benchmark/batch_run_tests) and [here (result visualization)](https://github.com/JiayuSuPKU/SPLISOSM_paper/tree/main/scripts/benchmark/visualization).

## Real world data
### Overview of ST datasets with isoform-level quantification
* Mouse (n=5):
  1. 3 Visium-ONT (SiT) datasets of mouse olfactory bulb (MOB), coronal brain section (CBS1, CBS2)
  2. 1 Visium-SR dataset of coronal brain section (CBS)
  3. 1 Slide-seqV2-SR dataset of mouse hippocampus (Puck_200115_08)
* Human (n=36):
  1. 12 Visium-SR datasets of human dorsolateral prefrontal cortex (DLPFC) samples (151507, 151508, 151509, 151510, 151669, 151670, 151671, 151672, 151673, 151674, 151675, 151676)
  2. 11 Visium-ONT datasets of human glioma samples (DMG_1, DMG_2, DMG_3, DMG_4, DMG_5, GBM_1, GBM_2, GBM_3, GBM_4, GBM_5, GBM_6)
  3. 13 Visium-SR datasets of human glioma samples (MGH258, ZH881inf, ZH881T1, ZH916bulk, ZH916inf, ZH916T1, ZH1007inf, ZH1007nec, ZH1019inf, ZH1019T1, ZH8811Abulk, ZH8811Bbulk, ZH8812bulk)

### Data sources
Raw and processed datasets are downloaded from various sources, including:
1. The *processed* SiT data of adult mouse brain (`data/sit_nar_23/`) downloaded from Gene Expression Omnibus ([GSE153859](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE153859)).
2. The Visium data of adult mouse brain (`data/visium_mouse_cbs/`) downloaded from https://www.10xgenomics.com/datasets/adult-mouse-brain-coronal-section-fresh-frozen-1-standard.
3. The Slide-seqV2 data of adult mouse hippocampus (`data/slideseqv2_mouse_hippo/`) downloaded from https://singlecell.broadinstitute.org/single_cell/study/SCP815/sensitive-spatial-genome-wide-expression-profiling-at-cellular-resolution#study-summary.
4. The Visium data of human DLPFC (`data/human_dlpfc/`) downloaded through [Globus (endpoint: jhpce#HumanPilot10x)](https://research.libd.org/globus/jhpce_HumanPilot10x/index.html).
5. The *processed* Visium-ONT data of human glioma samples (`data/gbm_ont_nc_23/`) obtained from the authors of the original study [Ren et al. 2023](https://www.nature.com/articles/s41467-023-36707-6).
6. The Visium data of human glioblastoma samples (`data/gbm_visium_cell_24/`) downloaded from Sequence Read Archive ([PRJNA994130](https://www.ncbi.nlm.nih.gov/sra/PRJNA994130)).

References to the original studies and descriptions on data processing can be found in the corresponding Methods sections of the [SPLISOSM paper](https://www.biorxiv.org/content/10.1101/2025.05.02.651907v1.full). In brief, for long-read ONT data, we use directly the processed isoform quantification results from the original studies; for short-read data, we use [Sierra](https://github.com/VCCRI/Sierra/tree/master) for transcript 3'end diversity (TREND) quantification.
